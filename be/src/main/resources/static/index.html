LinkPet API Serviço ativo

API do LinkPet.

Serviço REST em Java que autentica usuários, guarda seus links e faz o pet virtual evoluir a cada curtida. Esta é a raiz da API — o app de verdade fica no frontend.

Abrir o app Ver endpoints

Endpoints principais

Uma amostra da API — payloads completos no código-fonte.

POST /usuarios cria uma conta
POST /usuarios/login autentica e devolve um JWT
GET /usuarios/me dados do usuário autenticado
GET /p/{username} página pública de links, sem autenticação
POST /p/{username}/pet/like alimenta o pet virtual
POST /usuarios/{id}/links cria um link (autenticado)
